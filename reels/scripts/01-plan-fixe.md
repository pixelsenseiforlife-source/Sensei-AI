# Reel 01 — Le mouvement le plus puissant
**Notion :** plan fixe · **Durée :** ~30 s · **Objectif :** audience · **CTA :** abonnement

## Accroche (0–2 s)
L'élève agite son téléphone dans tous les sens. Texte écran : **« TU BOUGES TROP. »**

## Voix off
```voix-off
Tu bouges ta caméra tout le temps ? <break time="0.4s" /> Arrête.
Le mouvement le plus puissant, c'est souvent… de ne pas bouger.
Le plan fixe : caméra posée, sur un trépied ou contre un mur. Et c'est ton sujet qui fait l'action. Il entre, il agit, il sort du cadre.
Le spectateur ne regarde plus ta technique. Il regarde l'histoire.
Règle du dojo : si ton mouvement n'a pas de raison… reste fixe.
Abonne-toi. Demain, on fait bouger la caméra. Mais avec une intention.
```

## Découpage animation
| Temps | Image | Texte écran |
|---|---|---|
| 0–2 s | L'élève filme en secouant le téléphone, image tremblée dans un cadre REC | TU BOUGES TROP. |
| 2–5 s | Le Sensei pose la main sur le téléphone. Tout s'arrête | STOP. |
| 5–11 s | Téléphone posé sur un trépied, schéma vu de dessus : caméra immobile | LE PLAN FIXE |
| 11–17 s | Dans le cadre : un personnage entre, s'assoit, se relève, sort | Le sujet agit, pas la caméra |
| 17–22 s | Zoom lent sur le visage d'un spectateur captivé | Il regarde l'histoire |
| 22–27 s | Tampon rouge qui s'imprime + gong | RÈGLE N°1 : PAS DE RAISON = PLAN FIXE |
| 27–30 s | Le Sensei pointe le bouton S'abonner | Demain : on bouge. |

## Légende
Le mouvement le plus puissant ? Ne pas bouger. 🎥
Un plan fixe bien pensé raconte plus qu'un mouvement sans intention.
